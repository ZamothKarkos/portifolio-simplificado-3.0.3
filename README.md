# Portifólio Simplificado 3.0.2

Um portfólio pessoal estático em HTML, CSS e JavaScript criado por Thomaz Mendes de Oliveira. O site apresenta uma seção de apresentação pessoal, links para redes sociais e cards de projetos com um botão para exibir projetos adicionais.

## Sobre o projeto

O projeto é uma landing page de portfólio simples e responsiva que inclui:

- Seção de boas-vindas com nome, descrição e interesses.
- Links para LinkedIn, WhatsApp, GitHub, Instagram e Facebook.
- Um carrossel/grade de projetos com imagens e descrições.
- Botão "Mostrar mais" que exibe projetos adicionais usando JavaScript.
- Design responsivo usando CSS personalizado.

## Tecnologias usadas

- HTML5
- CSS3
- JavaScript
- Font Awesome (ícones)
- Devicons (ícones de tecnologia)
- Google Fonts (`Playfair Display`)

## Estrutura do projeto

- `index.html` - página principal do portfólio.
- `src/css/reset.css` - reset de estilos básicos.
- `src/css/estilos.css` - estilos principais do portfólio.
- `src/css/responsivo.css` - estilos para responsividade.
- `src/css/nav-bar.css` - estilos específicos da barra de navegação.
- `src/js/index.js` - script que controla o botão "Mostrar mais".
- `src/imagens/` - imagens usadas no site.

## Como usar

1. Abra o arquivo `index.html` em um navegador moderno.
2. Navegue pela seção inicial e confira os links de redes sociais.
3. Role até a seção "Meus projetos".
4. Clique em "Mostrar mais" para revelar outros projetos.

## Observações

- O site é estático e pode ser hospedado em serviços como GitHub Pages.
- Algumas URLs de projeto já estão configuradas para GitHub Pages.
